# Binary Tree Visualization with C# Windows Forms

## Overview

This project was developed to better understand and visualize the logic of tree data structures using **C# Windows Forms**.

The application allows users to create and manage tree nodes interactively while demonstrating core tree operations and traversal algorithms through a graphical interface.

## Features

- Add node operation
- Delete node operation
- Search node operation
- Tree traversal algorithms:
  - Preorder
  - Inorder
  - Postorder
- Display total node count
- Display tree height
- Display leaf nodes
- Interactive Windows Forms interface

## Technologies Used

- C#
- Windows Forms
- Object-Oriented Programming

## Purpose of the Project

The purpose of this project is to reinforce the understanding of tree data structures and traversal algorithms through practical implementation and visualization.
